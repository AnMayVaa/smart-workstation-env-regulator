## วิธีส่งงาน (ไม่ต้องใช้ git ก็ได้)

1. เปิดโฟลเดอร์ที่ถูกต้องบนหน้าเว็บ GitHub
2. กด **Add file → Upload files** แล้วลากไฟล์มาวาง
3. ช่อง commit message เขียนสั้นๆ เช่น `ส่ง B2 logic presence v1`
4. กด **Commit changes**
5. แจ้งในกลุ่มแชท เช่น "ส่ง B2 แล้ว @A"

## ตั้งชื่อไฟล์

- ไฟล์ Word / PDF / PNG: ใช้รูปแบบ `รหัส_ชื่อสั้น_vเลข` ตามไฟล์ภาพรวม เช่น `B2_logic_presence_v1.docx`
- ถ้าแก้งานที่ส่งแล้ว อย่าทับไฟล์เดิม ให้อัปโหลดเป็นเวอร์ชันใหม่ (v2, v3) แล้วแจ้งคนที่ใช้งานชิ้นนั้น
- ไฟล์ `.md` (เช่น A1) ไม่ต้องใส่เลขเวอร์ชันในชื่อ เพราะ git เก็บประวัติให้ เวอร์ชันระบุไว้ที่หัวไฟล์
