## 1. กรณีทดสอบเฉพาะโมดูลอากาศ (Unit Tests: C-TC)

ตามแบบฟอร์ม TC ที่กำหนดในคู่มือบทบาท:

| รหัส | ประเภท (unit / system) | ทดสอบอะไร | สภาพก่อนเริ่ม (Precondition) | สิ่งที่กระทำ / ค่าที่ป้อนเข้า (Test Input / Action) | ผลที่ควรได้ตามข้อกำหนด (Expected Output) | ตรวจ Requirement ข้อไหน | ทดสอบใน Wokwi ได้ไหม (และใช้อะไรแทน) |
|---|---|---|---|---|---|---|---|
| **TC-C-01** | Unit Test | การเปิดพัดลมดูดอากาศเต็มกำลัง และแสดงไฟแดงเมื่อ $\text{CO}_2$ สูงเกินเกณฑ์ | ห้องมีคนทำงาน (`room_occupied_count = 1`), ค่า $\text{CO}_2 = 700\ \text{ppm}$, พัดลมปิด (`PWM = 0%`), ไฟสถานะสีเขียว | ปรับค่าความต้านทาน (Potentiometer) หรือส่งค่า $\text{CO}_2$ จำลองเพิ่มขึ้นเป็น $1050\ \text{ppm}$ | ภายใน 5 วินาที: พัดลมดูดอากาศติดทำงานที่ `PWM = 100%`, ไฟสถานะเปลี่ยนเป็น **สีแดง**, และตัวแปร `alert_request` มีค่าเป็น `"CO2_HIGH"` | FR-AIR-01 (เปิดพัดลมเมื่อ $\text{CO}_2 \ge 1000\ \text{ppm}$), NFR-RT-01 (ตอบสนองใน 5s) | **ได้** (ใช้ Potentiometer แทน CO₂ และ Relay/LED แทนพัดลม) |
| **TC-C-02** | Unit Test | การทำงานของกลไก Hysteresis เพื่อป้องกันพัดลมตัดต่อถี่ๆ | ห้องมีคนทำงาน (`room_occupied_count = 1`), พัดลมกำลังทำงานที่ `PWM = 100%`, ค่า $\text{CO}_2 = 1050\ \text{ppm}$, ไฟสีแดง | ค่อยๆ ปรับลดค่า $\text{CO}_2$ ลงมาที่ $920\ \text{ppm}$ (ต่ำกว่า 1000 ppm แต่ยังสูงกว่า 800 ppm) | พัดลมยังต้องทำงานต่อเนื่อง (ลดรอบลงมาที่ `PWM = 60%`), ไฟสถานะเปลี่ยนเป็น **สีเหลือง**, พัดลม **ต้องไม่ดับสนิท** จนกว่าค่า $\text{CO}_2$ จะลดลงต่ำกว่า $800\ \text{ppm}$ | FR-AIR-02 (Hysteresis ป้องกัน Fan Cycling), NFR-REL-01 (เสถียรภาพกลไก) | **ได้** (ปรับค่า Potentiometer ลดระดับทีละขั้น) |
| **TC-C-03** | Unit Test | การปิดพัดลมสมบูรณ์เมื่อคุณภาพอากาศกลับมาอยู่ในเกณฑ์ดี | ห้องมีคนทำงาน, พัดลมกำลังหมุนที่ `PWM = 60%`, ค่า $\text{CO}_2 = 850\ \text{ppm}$, ไฟสีเหลือง | ปรับลดค่า $\text{CO}_2$ ลงมาจนถึง $750\ \text{ppm}$ (ต่ำกว่าจุดตัด Hysteresis ล่าง $800\ \text{ppm}$) | พัดลมดับสนิท (`PWM = 0%`), ไฟสถานะเปลี่ยนกลับเป็น **สีเขียว**, `air_level = 0` | FR-AIR-01, FR-AIR-02 | **ได้** |
| **TC-C-04** | Unit Test | โหมดประหยัดพลังงานเมื่อไม่มีคนอยู่ในห้อง (`ROOM_EMPTY`) | ค่า $\text{CO}_2 = 1200\ \text{ppm}$, พัดลมกำลังหมุนเต็มกำลัง (`PWM = 100%`) | ป้อนค่า `room_occupied_count = 0` (สัญญาณจำลองจากโมดูลตรวจคนว่าทุกคนออกจากห้องแล้ว) | พัดลมหยุดทำงานทันที (`PWM = 0%`) และไฟสถานะ RGB ดับลงเพื่อประหยัดพลังงาน | FR-PWR-01 (ระบบประหยัดพลังงานอัตโนมัติ) | **ได้** (จำลองตัวแปร `room_occupied_count = 0`) |
| **TC-C-05** | Unit Test | โหมดนิรภัยกรณีเซนเซอร์ชำรุดหรืออ่านค่าไม่ได้ (Fail-Safe Mode) | ระบบกำลังทำงานปกติที่สถานะใดๆ | ตัดสายสัญญาณ I²C หรือหยุดส่งข้อมูลจาก SCD41 เป็นเวลา $\ge 15\ \text{วินาที}$ (พลาดเกิน 3 รอบ) | ระบบต้องไม่แฮงก์ (No crash/hang), สั่งเปิดพัดลมดูดอากาศทันทีที่ `PWM = 80%`, ไฟสถานะ **กะพริบสีแดง**, และส่ง `alert_request = "AIR_SENSOR_ERROR"` | FR-SAFE-01 (Fail-Safe เมื่อเซนเซอร์ขัดข้อง บท 6 หน้า 22–26) | **ได้** (จำลองโดยแก้โค้ดให้ฟังก์ชันอ่าน I2C คืนค่า error) |
| **TC-C-06** | Unit Test | การตรวจจับและแจ้งเตือนอุณหภูมิห้องไม่เหมาะสม | อุณหภูมิปกติ $22^\circ\text{C}$, ไม่มีแจ้งเตือนอุณหภูมิ | ปรับค่าอุณหภูมิบนเซนเซอร์ DHT22 ให้สูงเกิน $26^\circ\text{C}$ หรือต่ำกว่า $19^\circ\text{C}$ | ระบบยังคงควบคุมพัดลมตามค่า $\text{CO}_2$ ตามปกติ แต่สร้าง `alert_request` สำหรับอุณหภูมิแจ้งเตือนผู้ใช้โดยไม่กระทบต่อการทำงานของระบบควบคุมพัดลม | FR-AIR-03 (แจ้งเตือนอุณหภูมิห้อง) | **ได้** (ใช้สไลเดอร์ปรับอุณหภูมิบน DHT22 ใน Wokwi) |

## 2. โครงสร้างแม่แบบสำหรับ C5 (แผนทดสอบรวมทั้งระบบ - System Integration Test Plan)

เมื่อได้รับ Test Cases จากสมาชิกคนอื่น (A-TC, B-TC, D-TC) ซัน (C) จะนำมารวบรวมลงในเอกสาร **C5_test_plan_v1** ตามหมวดหมู่ดังนี้:

1. **ส่วนที่ 1: การทดสอบรายโมดูล (Unit Testing - อ้างอิงบทที่ 7–8):**
   - *โมดูล A:* การเชื่อมต่อ Wi-Fi ระหว่าง 2 บอร์ด, การซิงก์เวลา NTP, Mutex I²C Protection
   - *โมดูล B:* เซนเซอร์ตรวจจับคน (mmWave/PIR), การนับเวลานั่ง 20/30 นาที, จอ OLED และ Buzzer แจ้งเตือนพักสายตา
   - *โมดูล C:* ตรวจวัด $\text{CO}_2$, การตัดต่อพัดลมด้วย Hysteresis, Fail-safe mode, การประหยัดพลังงานเมื่อห้องว่าง (จากตารางด้านบน)
   - *โมดูล D:* เซนเซอร์วัดแสง BH1750, การปรับความสว่างไฟโต๊ะรักษาระดับ 500 lux ด้วย PWM, การเปลี่ยนโทนสีแสงตามช่วงเวลา (NTP)
2. **ส่วนที่ 2: การทดสอบร่วมข้ามระบบ (System & Integration Testing):**
   - *TC-SYS-01:* การจำลองผู้ใช้นั่งทำงาน 30 นาที $\rightarrow$ โต๊ะเตือนพัก 20/30 นาที พร้อมกับค่า $\text{CO}_2$ ในห้องสะสมถึง 1000 ppm $\rightarrow$ โหนดห้องสั่งเปิดพัดลมดูดอากาศ และส่งสถานะ $\text{CO}_2$ ข้าม Wi-Fi มาขึ้นจอ OLED บนโต๊ะพร้อมกันอย่างถูกต้อง
   - *TC-SYS-02:* การจำลองผู้ใช้ลุกออกจากห้อง $\rightarrow$ โหนดโต๊ะนับเวลาครบ 5 นาที สั่งปิดโคมไฟตั้งโต๊ะ และส่ง `room_occupied_count = 0` ข้าม Wi-Fi ไปยังโหนดห้อง $\rightarrow$ โหนดห้องสั่งปิดพัดลมระบายอากาศทันที
