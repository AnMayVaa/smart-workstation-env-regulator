# หลักฐานการทดสอบ Wokwi รอบ 14 ต.ค. 2569

สรุปผลและการตีความอยู่ที่ `06_testing/A5_results.md` · โฟลเดอร์นี้เก็บเฉพาะหลักฐานดิบ ไม่มีการแก้ไขหลังรัน

## ชนิดไฟล์

| ชนิด | ไฟล์ | คืออะไร |
|---|---|---|
| **ภาพ** | `NN_<ชื่อ>.png` | ภาพจอ OLED 128 × 64 ที่ถ่ายอัตโนมัติตามลำดับในการทดสอบ (เลขนำหน้า = ลำดับ) |
| **log** | `console.log` | ผลจาก Wokwi CLI: เวลา wall `[wall 12.345]` + เวลาระบบจำลอง `[ 12.345]` + ขั้นตอนที่สคริปต์สั่งและข้อความที่รอได้ |
| **log** | `serial.log` | ข้อความ Serial จาก ESP32 ล้วน (ข้อมูลดิบ ไม่มีขั้นตอนสคริปต์ปน) |
| **ข้อมูลดิบ** | `logic_analyzer_vcd.zip` | ไฟล์ `.vcd` ของ logic analyzer ทุกการทดสอบ (เปิดด้วย PulseView) |
| **ข้อมูลวิเคราะห์** | `vcd_summary.txt` | ความถี่/duty ของ PWM ทุกช่วงเวลา และจังหวะ beep ที่คำนวณจาก VCD ด้วย `08_code/ci/vcdsum.py`, `beeps.py` |

ช่องของ logic analyzer: โหนดโต๊ะ D0 = GPIO 18 (LED ขาวเย็น), D1 = GPIO 19 (LED ขาวอุ่น), D2 = GPIO 26 (buzzer) · โหนดห้อง D0 = GPIO 25 (พัดลม)

## แต่ละโฟลเดอร์

| โฟลเดอร์ | โหนด / firmware | ทดสอบ (ID ใน A5) | ภาพ |

| `room_b` | ห้อง | R6–R7: SCD41 เสีย/กลับ, ค่าเกินช่วง, ธงอุณหภูมิ | — |
| `desk_a` | โต๊ะ, TIME_SCALE 120 | D1–D4: เมนูตั้งค่า, เตือน EYE/STAND, รับทราบ, snooze สูงสุด 2 ครั้ง | 13 ภาพ |
| `desk_b` | โต๊ะ, TIME_SCALE 120 | D5, D6, D8, D9: คุม lux, สีแสงตามเวลา, BH1750/LD2410 เสีย | 2 ภาพ |

| `desk_d` | โต๊ะ, TIME_SCALE 120 (ปิด Wi-Fi) | D7: หรี่ค้าง 60 s แล้วปิดไฟ | 1 ภาพ |
