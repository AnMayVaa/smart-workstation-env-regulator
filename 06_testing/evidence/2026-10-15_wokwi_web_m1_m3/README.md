# M1 และ M3: รันต่อเนื่องบน wokwi.com (15 ต.ค. 2569)

รันบนโปรเจค public ทั้ง 2 ตัว (โค้ดตรงกับ `08_code` ทุกไฟล์) ในเบราว์เซอร์ ไม่ใช่ Wokwi CLI

| ไฟล์ | ชนิด | คืออะไร |
|---|---|---|
| `desk_serial.log` | **log** | Serial ของโหนดโต๊ะ (`TIME_SCALE 1` เวลาจริง) 22.8 นาทีจำลอง: เหตุการณ์ทั้งหมด, `status`, `stats` 2 ครั้ง |
| `room_serial.log` | **log** | Serial ของโหนดห้อง 10.5 นาทีจำลอง: เหตุการณ์ FSM, `stats` (ตัดบรรทัด `status` ที่ซ้ำออก) |

- **M3:** เริ่มนั่ง `[ 129.875]` → `EYE BREAK` `[ 1330.076]` = 20 นาที 0.2 วินาที
- **M1:** ระหว่างรันมีเหตุการณ์: CO₂ 1,200/970/920/700/1,100 ppm, SCD41 เสีย/กลับ, อุณหภูมิ 27/18 °C, BH1750 เสีย/กลับ, Wi-Fi โต๊ะหลุด 39 s แล้วต่อกลับ, ตั้งนาฬิกา 16:55 (สีแสงเปลี่ยน)
- เบราว์เซอร์หยุดแท็บที่ไม่ได้แสดง จึงรันห้องและโต๊ะสลับกันเป็นช่วง ช่วงที่อีกโหนดหยุด โต๊ะเห็นลิงก์ขาด (`link_ok=0`, `air_lost`) เป็นผลของการทดสอบ ไม่ใช่ข้อผิดพลาด
