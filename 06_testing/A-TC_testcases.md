## หมายเหตุถึง C

- TC-A-01 ถึง TC-A-03 เดิมใน C5 ใช้รหัส requirement คนละชุดกับ D1 (เช่น FR-AIR-01) ชุดนี้ใช้รหัส D1 แล้ว
- TC-A-01 เดิมคาดว่า `alert_request` ส่งข้าม Wi-Fi แต่ A1 v1.0 กำหนดให้ข้อมูลอากาศไปทาง `air_status` อย่างเดียว ผลที่ควรได้จึงตรวจจากจอโต๊ะแทน
- TC-A-04 และ TC-A-06 เป็นกรณีใหม่ ตรวจ `room_desks_online` และ NFR-13 ที่ยังไม่มี test case
